# Contributing

Thanks for helping improve the Byson Cyber Community Website Security Audit!

## Before proposing changes

1. Open an issue describing the observed behavior and how to reproduce it without sharing private target data.
2. Run `./Test-WebAudit-Syntax.ps1` in Windows PowerShell 5.1 or PowerShell 7.
3. For behavior changes, test **only against a site you control or have permission to assess**, and mention which PowerShell version and `curl` version you used.
4. Keep requests low-impact. Do not add brute forcing, credential testing, exploitation, or unchecked active probes.
5. Avoid external module dependencies and preserve noninteractive command-line usage and the guided wizard.

By contributing code, you agree that it may be distributed under the repository's MIT license.
